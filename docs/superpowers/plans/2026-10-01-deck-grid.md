# HitRate Deck Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace HitRate's launch list with a simple two-column grid of portrait, lightly three-dimensional deck cards while preserving all existing data, sync, entitlement, and navigation behavior.

**Architecture:** Keep `Team` and `FolderListView` as the storage and routing foundations. Add a focused, query-free `DeckGridCard` component and a small pure copy formatter, then replace only the launch screen's row layout with `LazyVGrid`; existing sheets and actions remain wired to the same state.

**Tech Stack:** Swift 5, SwiftUI, SwiftData, XCTest, XcodeGen, iOS 17+

**Spec:** `docs/superpowers/specs/2026-10-01-deck-grid-design.md`

## Global Constraints

- Keep `Team` as the SwiftData and Firestore model; do not change the schema or cloud document shape.
- Each `StuntGroup` remains related to exactly one `Team`/deck.
- Cold launch opens the deck grid; onboarding and new-deck creation still open the newly created deck directly.
- Use the graphite training-floor register; green remains reserved for go/hit/improving state.
- Use a two-column grid of equal portrait card stacks with two thin layers and restrained shadow.
- Do not add featured decks, shelves, opening animation, dramatic tilt, carousels, nested decks, cross-deck statistics, shared cards, custom artwork, or drag-and-drop ordering.
- Preserve sharing, joining, account, paywall, Trash, sync-listener, watch, and dashboard behavior.
- Preserve concurrent work and stage only task-owned hunks.

## Review Focus

- Long deck names: remain readable at large Dynamic Type and never overlap the count summary; covered by Task 2's accessibility-size simulator check.
- Zero and singular counts: render `0 skills · 0 reps` and `1 skill · 1 rep`; covered by Task 1 unit tests.
- Shared versus joined ownership: expose the correct visible badge and VoiceOver text without offering owner-only sharing to a joined member; covered by Tasks 1 and 3.
- Odd deck counts and one-deck free tier: preserve a stable two-column grid and keep the New Deck affordance/paywall boundary; covered by Task 3 unit/build checks and Task 4 simulator verification.
- Exact deck routing: tapping deck B must set/open deck B, not a stale fallback deck; covered by Task 3's routing preservation review and Task 4's multi-deck simulator verification.

```swift
import SwiftUI

enum DeckSharingState: Equatable {
    case privateDeck
    case shared
    case joined

    var accessibilitySuffix: String? {
        switch self {
        case .privateDeck: nil
        case .shared: "shared deck"
        case .joined: "joined deck"
        }
    }
}

enum DeckGridCardCopy {
    static func summary(skillCount: Int, repCount: Int) -> String {
        "\(skillCount) skill\(skillCount == 1 ? "" : "s") · "
        + "\(repCount) rep\(repCount == 1 ? "" : "s")"
    }

    static func accessibilityLabel(
        name: String,
        skillCount: Int,
        repCount: Int,
        sharingState: DeckSharingState
    ) -> String {
        let counts = summary(skillCount: skillCount, repCount: repCount)
            .replacingOccurrences(of: " · ", with: ", ")
        return ["\(name) deck", counts, sharingState.accessibilitySuffix]
            .compactMap { $0 }
            .joined(separator: ", ")
    }
}
```

- [ ] **Step 1: Add the card component below the pure copy types**

Implement this public shape and rendering structure:

```swift
struct DeckGridCard: View {
    let name: String
    let summary: FolderSummaryIndex.Summary
    let sharingState: DeckSharingState
    let isActive: Bool
    let canTrash: Bool
    let onOpen: () -> Void
    let onShare: (() -> Void)?
    let onRename: () -> Void
    let onTrash: () -> Void

    var body: some View {
        Button(action: onOpen) {
            VStack(alignment: .leading, spacing: 9) {
                ZStack {
                    deckLayer.offset(x: 6, y: 7).opacity(0.45)
                    deckLayer.offset(x: 3, y: 4).opacity(0.72)
                    cover
                }
                .aspectRatio(0.69, contentMode: .fit)

                Text(name)
                    .font(.system(size: 14, weight: .semibold))
                    .foregroundStyle(Theme.label)
                    .lineLimit(2)

                Text(DeckGridCardCopy.summary(
                    skillCount: summary.skillCount,
                    repCount: summary.repCount
                ))
                .font(.system(size: 11, weight: .medium))
                .foregroundStyle(Theme.label2)
                .lineLimit(1)
                .minimumScaleFactor(0.8)
            }
            .frame(maxWidth: .infinity, alignment: .leading)
            .contentShape(Rectangle())
        }
        .buttonStyle(.plain)
        .accessibilityElement(children: .ignore)
        .accessibilityLabel(DeckGridCardCopy.accessibilityLabel(
            name: name,
            skillCount: summary.skillCount,
            repCount: summary.repCount,
            sharingState: sharingState
        ))
        .accessibilityHint("Opens this deck")
        .accessibilityAction(named: "Rename", onRename)
        .contextMenu { menu }
    }
}
```

Use a portrait `RoundedRectangle(cornerRadius: 13, style: .continuous)` for `deckLayer` and `cover`. The cover uses `Theme.well`, `Theme.iconTileEdge`, `Theme.label`, and `Theme.label2`; active state may strengthen the neutral border but must not turn the cover green. Put `SHARED` or `JOINED` in a small neutral capsule on the cover. Use only two offset layers and one soft black shadow; do not rotate, glow, shimmer, or animate the stack.

The context menu must contain Rename, optional Share/Sharing Code, and conditional Move to Trash. Add the VoiceOver Share action only when `onShare` is non-nil, using a small conditional view helper rather than attaching a no-op action to joined decks. Do not place secondary `Button`s inside the primary `Button` label.

- [ ] **Step 3: Wire each Team into DeckGridCard without changing behavior**

Replace `folderRow` with:

```swift
private func deckCard(
    _ team: Team,
    summary: FolderSummaryIndex.Summary
) -> some View {
    DeckGridCard(
        name: team.name,
        summary: summary,
        sharingState: sharingState(for: team),
        isActive: team.id.uuidString == currentTeamID,
        canTrash: teams.active.count > 1,
        onOpen: { onOpen(team) },
        onShare: isOwner(team) ? {
            if coach.isCoach { sharing = team }
            else { paywallReason = .share }
        } : nil,
        onRename: {
            renameText = team.name
            renaming = team
        },
        onTrash: { pendingTrash = team }
    )
}

private func sharingState(for team: Team) -> DeckSharingState {
    if !isOwner(team) { return .joined }
    return isShared(team) ? .shared : .privateDeck
}

private func beginAddingDeck() {
    if CoachGate.allowsNewFolder(existingCount: teams.active.count) {
        addOpen = true
    } else {
        paywallReason = .secondFolder
    }
}
```

Do not change `addFolder`, `trashFolder`, `currentTeamID`, or `onOpen` routing semantics.
